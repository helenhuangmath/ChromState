# demo

Simulate a two-condition, six-mark experiment with known states and run everything on it: write the inputs, read them back, fit, quantify, benchmark and plot.

## Example

```bash
chromstate demo -o demo_out
```

It takes about 15 s and writes 13 figures, 12 tables and `demo_out/REPORT.md`. Use it
to check an installation and to see every output file on a small example.
