# Paper figures and legends

Drawn by `tools/make_paper_figures.py` from saved run tables; every number in a legend is read from the table its panel draws. Double column (183 mm), Arial 5-7 pt, vector PDF with editable text.

**Figure 1 | Recovery of known chromatin states on simulated data.** Nine methods were run on the same simulated counts (200,000 bins, seven true states); tools marked * are reimplementations of the published model, the others are the published software. ChromState is highlighted. **a**, Agreement of the called states with the truth (ChromState 0.84, ChromHMM 0.74, EpiCSeg 0.67). **b**, Detection of truly bivalent bins, scored with one rule for all tools. **c**, Spearman correlation between each tool's activity score and the simulated signal. **d**, Detection of the bins moved by a simulated perturbation from each tool's control-versus-treated change; dashed line, expected value for a random ranking (0.03). **e**, Expected calibration error of the state posterior; n.a., tool returns no posterior. **f**, Wall-clock time against data size for the published tools on one machine. The simulation draws counts from a negative-binomial model, the family ChromState fits, so these panels favour ChromState; Figure 2 gives the comparison on real data.

**Figure 2 | Six tools on real data, scored on genes and RNA-seq they never saw.** Top row, CD8 T cells (naive, memory, exhausted; CUT&RUN for H3K4me3, H3K27ac, H3K27me3, H3K9me3; chromosome 19; 15 states). Middle row, GM12878, K562 and H1 (ENCODE ChIP-seq, six marks; chromosome 19; 18 states). ChromState is highlighted. **a**,**e**, Area under the precision-recall curve for finding promoters of expressed genes from each tool's states (bars, all samples; dots, one sample each; dashed line, random ranking). EpiCSeg is highest in both data sets (0.25 and 0.43); ChromState is second (0.24 and 0.41). **b**,**f**, Spearman correlation between measured expression and expression predicted from promoter states on held-out genes; lines, 95% bootstrap intervals; diamond, the same model given the raw mark signal instead of states. **c**,**g**, The same for the change in expression between two conditions (exhausted versus naive; K562 versus GM12878). In CD8 T cells ChromState is highest (0.36; raw signal 0.34); in the ENCODE data EpiCSeg and the raw signal are higher (0.53 and 0.51 against 0.49), with overlapping intervals. **d**,**h**, Wall-clock time. **i**,**j**, Pairwise agreement of the segmentations. **k**, Agreement of each tool's ENCODE segmentation with the published Roadmap 18-state annotation of the same cell type; that annotation was made with ChromHMM.

**Figure 3 | Replicated comparison of chromatin states between CD8 T-cell conditions.** One 15-state model was fitted to 16 CUT&RUN samples (eight naive from two batches, four memory, four exhausted; four marks; five chromosomes). **a**, Mark level in each state (log(1 + mean count), scaled to each mark's maximum). **b**, Share of the genome in each state for every replicate. **c**, Percentage of 307,986 2-kb tiles in which a state's share rose (right) or fell (left) in exhausted relative to naive cells (moderated t-test per tile and state, Benjamini-Hochberg FDR 5%). **d**, Change in each state's genome share relative to naive cells, with 95% block-bootstrap intervals; grey, the same statistic between the two batches of naive cells. Batch alone moves a state by up to 2.1 percentage points (Quiescent, low signal (4)), so genome-wide shifts of that size are not evidence of a condition effect. **e**, Cumulative distribution of the per-tile change in state composition; dashed line, the noise floor estimated from replicate pairs. **f**, Percentage of regions called changed (FDR 5% and above the noise floor). The contrast between the two naive batches calls 0.015% of tiles and 0.11% of promoters; exhausted versus naive calls 26.7% and 23.5%.

**Figure 4 | Chromatin states predict gene expression, and which states do.** Per-gene state tables (promoter and gene body) were used to predict RNA-seq with gradient-boosted trees; every prediction is for genes on chromosomes held out of training. Orange, CD8 T cells (CUT&RUN, 4 marks); green, ENCODE cell lines (ChIP-seq, 6 marks). **a**, Predicted against measured expression in CD8 T cells (colour, number of points, log scale). **b**,**c**, Accuracy for expression level (**b**) and for the change between two conditions (**c**; exhausted versus naive, K562 versus GM12878) when the gene is described in six ways; lines, 95% bootstrap intervals. For level, quantitative states add little over the raw signal (0.80 against 0.79 in CD8 T cells). For change, a hard state label loses most of the information (0.16 against 0.53 in CD8 T cells; 0.49 against 0.68 in ENCODE). **d**,**e**, Drop in held-out R² when one state's columns are permuted (95% intervals); the eight largest are shown. Active transcription start site is first in both (0.31 and 0.36). **f**, Accuracy from promoter columns, gene-body columns, or both (circles, level; triangles, change).

*File: `Fig4_expression.pdf`, 183 x 126 mm.*

**Figure 5 | External checks of an 18-state ChromState model on ENCODE data.** One model was fitted to six histone marks in GM12878, K562 and H1 (two replicates each; chromosomes 1, 8, 11, 19 and X). **a**, Mark level in each state. **b**, Share of the genome in each state for every replicate. **c**, Enrichment of STARR-seq enhancer activity in K562 in each state (bars, mean; dots, the two replicates); the most enriched state is Active transcription start site (3) (9.0-fold). **d**, Agreement with the Roadmap 18-state annotation of the same cell type (ARI 0.13-0.21) and between the two replicates of a cell type (0.27-0.49). Replicates of one cell type agree only moderately, which bounds how far any single-replicate segmentation should be trusted. **e**, Ranking of 2,145 CRISPRi-tested K562 elements (187 regulate a gene) by three ChromState scores and by the raw H3K27ac signal; dashed line, random ranking. The raw signal (0.30) is not improved on by the state scores (0.28 for the share of active states), and the states the model names as enhancers rank below chance (0.05): the validated elements sit in promoter-like states. **f**, Calibration error of the state posterior, measured as agreement between replicates, before and after temperature scaling (the temperature was fitted on the same bins).
